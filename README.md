# Backend - Node.js + Express

Backend desarrollado con **Node.js** utilizando **Express Generator**.

## Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- Node.js, El proyecto se creo con una versión de Node JS v24.13.1
- npm

Puedes validar las versiones con:

node -- version
npm --version

## Instalación
1. Clona el repositorio y entra a la carpeta del backend. cd backend
2. Instala las dependencias:, npm install
